General Instructions

  1. This is a practice with the same format as the real quiz. Use it to prepare.
  2. Read the entire test carefully and ensure you understand what is being asked before answering.
  3. Gravitational Acceleration: Use $g = 9.8\text{ m/s}^2$ for all calculations.
  4. Allowed Materials: Pen, pencil, eraser, and scientific calculator. You are not allowed to borrow or lend materials.
  5. Electronic Devices: Cell phones, smartwatches, and other electronic devices must remain turned off and stored inside backpacks. They must not be kept inside clothing pockets.
  6. Multiple Choice: Select the single correct option. There is no penalty for incorrect choices.
  7. Numerical Answers: Enter only the numerical value in the indicated unit. A small margin is accepted for decimal rounding.
  8. Interactive Simulations: Perform your calculations first, then set or run the simulation. You have only 1 attempt per interactive problem.
  9. Ensure all questions have an answer before submitting. If a connection error occurs, save the PDF report and send it to your teacher.

Security Rules (same as the real quiz)

  • The practice opens in mandatory full screen mode.
  • If you switch tabs, minimize the browser, or exit full screen, you will receive one warning. A second exit will automatically lock and submit your practice with your current score.
